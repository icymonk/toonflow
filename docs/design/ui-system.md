# UI 디자인 시스템

> 상태: 확정 · v1.1 · 2026-10-21 — 원본 기획 3·4·6·8절 기준.

## 1. 원칙
- 창작 도구답게 에너지가 있되, **매일 오래 써도 피곤하지 않게.**
- **코랄은 중요한 행동에만.** 화면 하나에 코랄 주 버튼은 1개가 원칙. 배지·아이콘을 코랄로 칠하지 않는다.
- 제작 화면은 **장식보다 작업 공간.** 여백·카드 그림자보다 캔버스 크기를 우선.
- 모든 비동기 동작은 **로딩 · 비활성 · 성공 · 실패** 상태를 항상 보인다.

### 2-2. 대비 점검 (보강)
본문 글자 기준 4.5:1, 큰 글자·아이콘 기준 3:1 (WCAG AA).

| 조합 | 대비 | 판정 |
| --- | --- | --- |
| Ink Navy 글자 / Warm Canvas | 14.3:1 | 통과 |
| Text Secondary / Warm Canvas | 4.9:1 | 통과 |
| Success · Warning · Error 글자 / Warm Canvas | 4.8 · 4.2 · 4.3:1 | 큰 글자·배지만. 작은 본문 글자로는 쓰지 않는다 |
| **흰 글자 / Flow Coral** | **2.7:1** | **미달** |
| **Ink Navy 글자 / Flow Coral** | **5.7:1** | 통과 |
| 흰 글자 / Coral Strong | 3.4:1 | 큰 글자만 |
| Flow Coral 글자 / Warm Canvas | 2.5:1 | 미달 — 코랄을 글자색으로 쓰지 않는다 |
| Soft Border / Warm Canvas | 1.2:1 | 장식선만. 입력 칸 테두리는 포커스 때 진하게 |

→ 주 버튼은 **코랄 배경 + Ink Navy 글자** (open-questions #16 결정). 코랄 위에 흰 글자를 쓰지 않는다. 링크 글자는 Ink Navy + 밑줄.

### 2-3. 토큰 (원본 8절)
| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `brand-primary` | Flow Coral | 주요 CTA, 현재 선택, 활성 탭 |
| `brand-strong` | Coral Strong | 강조 버튼 hover |
| `brand-on` | Ink Navy | 코랄 위 글자 |
| `surface-canvas` | Warm Canvas | 앱 배경 |
| `surface-panel` | Panel | 카드, 사이드 패널, 모달 |
| `surface-muted` | Panel Muted | 보조 영역 |
| `text-primary` / `text-secondary` | Ink Navy / Text Secondary | 글자 |
| `border-default` | Soft Border | 경계 |
| `focus-ring` | Ink Navy 2px + 2px 간격 | 키보드 포커스 |
| `status-success` / `status-warning` / `status-error` | 위 표 | 완료 / 검수 필요 / 생성 실패 |
| `status-neutral` | Text Secondary | 대기·미검수 등 "보통" 상태 |

- 상태 배지는 **연한 배경(같은 색 10%) + 진한 글자 + 아이콘**. 색만으로 상태를 구분하지 않는다.
- 상태별 색 배정은 [planning/glossary.md](../planning/glossary.md) 3절.
- 다크 모드 토큰은 4단계에 같은 이름으로 값만 바꿔 추가한다 (open-questions #20). 다크 배경 후보: Ink Navy 계열 `#171B29`, 패널 `#202538`.

## 4. 간격 · 모서리 · 그림자
- 간격 4px 단위: 4 · 8 · 12 · 16 · 24 · 32.
- 모서리: 입력·작은 버튼 8 / 카드 12 / 큰 패널·모달 16.
- 그림자는 떠 있는 요소(메뉴, 모달, 끌고 있는 컷)에만. 카드는 테두리로 구분.

## 5. 컴포넌트 (우선순위 순)
| 컴포넌트 | 규칙 |
| --- | --- |
| Button | Primary(코랄) / Secondary(테두리) / Ghost / Destructive(Error). 비용 드는 버튼은 **비용 표시 + 아이콘**(AIU-10). 실행 중엔 스피너 + 비활성 |
| Input · Textarea | 라벨 위, 오류 문구 아래, 긴 글은 글자 수, 저장 상태("저장됨 · 방금") |
| Status Badge | 제보·생성·검수·작업 상태. 연한 배경 + 아이콘 + 글자 |
| Panel Card | 에피소드·컷 썸네일. 썸네일 비율은 출력 비율과 같게, 상태 배지는 왼쪽 위 |
| Dialog · Drawer | 세부 설정, 후보 비교(넓은 Drawer), 삭제 확인 |
| Toast | 저장·생성 완료·실패. 실패 토스트는 "다시 시도" 버튼, 되돌릴 수 있는 동작은 "실행 취소" |
| Progress · Job Queue | 컷별 진행(썸네일 위), 전체 진행(대기열 패널 상단 n/m) |
| Empty State | 빈 목록마다 다음 행동 하나 (brand.md 2절 문구) |
| Command Palette | 메뉴·에피소드·컷 이동, 주요 동작 (2단계, STU-30) |

- 브라우저 기본 확인창(confirm/prompt)은 쓰지 않고 앱 Dialog를 쓴다.
- 아이콘은 한 세트(선 아이콘)로 통일.

## 6. 레이아웃 · 반응형
### 앱 셸
- 왼쪽 사이드바: **Ink Navy 배경**, 선택한 메뉴는 코랄 배경 + Ink Navy 글자. 로고 → 워크스페이스 이름 → 메뉴 → 아래쪽 Settings·사용량 막대·프로필. 메뉴는 Home, **제작**(Inbox·Stories·Studio·Publish), **라이브러리**(Styles·Characters·Assets) 묶음으로 나눈다([glossary](../planning/glossary.md) 1절). 접으면 아이콘만, 묶음 제목 대신 구분선.
- 위쪽 바: 현재 위치(작품 › 에피소드), 검색, 작업 대기열 아이콘(진행 중 개수), 알림.

### 제작실 (원본 6절)
```
┌ 위: 에피소드 제목 · 단계 탭 [Story|Storyboard|Illustrate|Review|Export] · 저장 상태 · 대기열 ┐
├ 왼쪽: 장·컷 목록 ─┬─ 가운데: 미리보기 / 편집 캔버스 ─┬─ 오른쪽: 선택한 컷의 속성 패널 ─┤
└──────────────────┴─────────────────────────────────┴───────────────────────────────┘
```
| 화면 폭 | 동작 |
| --- | --- |
| 데스크톱 (≥1280) | 세 영역 모두. 전체 편집 기능 |
| 태블릿 (768~1279) | 컷 목록·속성 패널을 접고 버튼으로 연다 |
| 모바일 (<768) | 제작실은 보기 전용 + 후보 선택 정도. 제보 검토·진행 상태·대기열 확인에 최적화 |

## 7. 접근성 · 상호작용
- 2-2절 대비 기준을 지킨다. 포커스 링은 항상 보인다.
- 모든 동작은 키보드로 가능. 제작실 단축키는 [features/studio.md](../features/studio.md) STU-30.
- 움직임은 짧게(150~200ms). "동작 줄이기" 설정을 따른다.
- 이미지 후보 비교는 **원본(이전 선택)과 나란히** (원본 4절).
