## 1. 브랜드 핵심
| 항목 | 내용 |
| --- | --- |
| 이름 | **TOONFLOW** (툰플로우). 글자 로고는 대문자 영문만, 문장 안에서는 `TOONFLOW` 그대로. 메뉴는 `Studio · 제작실`처럼 영문 + 한국어 설명 |
| 슬로건 | *Stories in. Comics out.* |
| 한국어 메인 카피 | 이야기를 넣으면, 웹툰이 완성된다. |
| 짧은 설명 | AI-powered comic creation studio / AI 웹툰 제작 스튜디오 |
| 핵심 약속 | 창작은 당신이, 반복 작업은 TOONFLOW가. |
| 성격 | 창의적 · 간결함 · 생산성 |
| 대상 | 1인 작가 · 인스타툰 크리에이터 |
| 핵심 가치 | 제작 시간 단축 |
| 장기 방향 | AI 콘텐츠 제작 SaaS. 브랜드는 인스타툰에만 묶지 않는다 |

## 3. 보이스 & 톤 (화면 문구 규칙)
- **짧고 구체적으로.** "작업이 처리되었습니다" 대신 "4컷 생성 완료".
- **해요체.** 존댓말이되 딱딱하지 않게. 느낌표는 성공 순간에만.
- **AI를 주어로 과장하지 않는다.** "AI가 완벽한 웹툰을 만들어 드려요"(X) → "각색 초안을 만들었어요. 고쳐서 쓰세요"(O). 핵심 약속과 맞춘다.
- **비용이 드는 행동은 숫자로.** "생성하기 · 4장 · 약 ₩280"처럼 버튼이나 옆에 표시 → [features/ai-usage.md](../features/ai-usage.md) AIU-10.
- **실패는 이유 + 다음 행동.** "생성 실패: 콘텐츠 정책에 걸렸어요. 장면 설명을 바꿔 다시 시도하세요."
- 메뉴는 `영어 · 한국어` 병기 ([planning/glossary.md](../planning/glossary.md)).

## 4. 로고
- **기본 로고**: Flow Panels 심볼(서로 이어진 컷 + 말풍선) + `TOONFLOW` 워드마크.
- **앱 아이콘·파비콘**: 심볼 단독, 또는 TF 모노그램.
- **다크 배경**: 밝은 크림색 심볼 + 코랄 포인트.
- **작은 크기(16~32px)**: 세부를 줄인 단순한 형태. 컷 2개 + 말풍선 꼬리 정도만.
- 로봇·마법봉 등 "AI" 상징은 쓰지 않는다. 기술이 바뀌어도 "컷의 흐름"이라는 의미는 유지된다.
- 필요한 파일: 가로형 로고, 세로형 로고, 심볼, 파비콘(16·32·180·512), 소셜 공유 이미지(1200×630), 밝은 배경용·어두운 배경용.
- 0단계는 **워드마크 글자 로고**로 시작하고, 심볼은 나중에 만든다 (open-questions #17).
