- 말풍선 글꼴 후보 확인 (1-I 전에, 라이선스 표로 드림)

## 검증 결과

### S1 이미지 모델 (2026-10-19, Gemini, 4:5 → 928×1152)
같은 캐릭터 설명 + 컷 10개. 1번 컷 결과를 2~10번 컷의 참조 이미지로 넣었다. 30장 모두 생성 성공, 차단 0.

| 모델 | 컷당 시간 | 출력 토큰 | 컷당 비용(₩, $1=₩1,400) | 같은 인물 유지 | 글자 없이 |
|---|---|---|---|---|---|
| **gemini-3.1-flash-lite-image (기본)** | 5초 | ~1,440 | ~61 | 좋음 | 거의 지킴(배경에 작은 장식 아이콘) |
| gemini-3.1-flash-image | 10초 | ~1,450 | ~61 | 좋음 | 배달 봉투 상호, 간판 글자가 들어감 |
| gemini-3-pro-image (고품질 선택지) | 17초 | ~1,280 | ~215 | 가장 좋음 | 엘리베이터 층 숫자 정도 |

- 세 모델 모두 참조 이미지로 같은 인물을 유지해서 CHR-04(참조 이미지)를 그대로 쓴다.
- 프롬프트에 "no text"를 넣어도 간판·상호·숫자는 가끔 그린다. 1-E 프롬프트에 "no signage, logos, numbers"를 추가하고, REV 단계의 검수 항목으로 남긴다.
- 상업 이용: Gemini API 약관상 생성물 권리는 사용자에게 있다(유료 등급은 입력·출력을 학습에 쓰지 않음). 출시 전 약관을 다시 확인한다.

### S2 글 모델 (2026-10-19)
실제 썰 형식 5개 → 6장 콘티 JSON(`responseMimeType: application/json`). 20건 모두 JSON 형식, 6장, 대사 종류 6종을 지켰다.

| 모델 | 건당 시간 | 출력 토큰(생각 포함) | 건당 비용(₩) | 대사 품질 |
|---|---|---|---|---|
| **gemini-3.8-flash (기본)** | 21초 | ~2,400 | ~13 (2027-01부터 단가 2배 → ~26) | 구체적 디테일, 인스타툰 말투, 효과음 활용 좋음 |
| gemini-3.5-flash-lite | 3초 | ~800 | ~3 | 무난하지만 밋밋함. 제목 추천 등 가벼운 작업용 |
| gemini-3.1-pro-preview | 24초 | ~3,000 | ~51 | 가장 풍부하지만 비용 4배, 미리보기 모델 |
| gemini-3.5-flash | 13초 | ~2,500 | (공개 가격표에 없음) | 좋음. 가격 미공개라 제외 |

- 콘티를 각색안과 나누지 않고 한 번에 만들어도 형식이 깨지지 않았다. 1-D에서는 그래도 SBD-01 설계대로 두 번에 나눠 부른다(각색안 수정 후 콘티만 다시 만들기 위해).
- 기본값은 `shared/config.ts`의 `DEFAULT_MODELS`. 운영자가 `/admin`에서 `config/models`를 저장하면 그 값이 우선한다.
