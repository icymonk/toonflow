# Stories · 작품 · 에피소드

> 상태: 확정 · v1.0 · ID 접두어 `EPI`

## 1. 목적
작품(연재 묶음)과 에피소드(게시물 한 편)를 만들고, 각 에피소드가 어느 제작 단계에 있는지 한눈에 본다.

## 2. 사용자 스토리
- "회사 생존기" 작품에는 늘 같은 주인공과 그림체를 쓰고 싶다.
- 작업 중인 에피소드가 어느 단계에서 멈춰 있는지 보고 싶다.
- 지난 에피소드를 복제해서 비슷한 구성으로 새 편을 만들고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 작품 | 같은 캐릭터·그림체를 쓰는 연재 묶음. 기본 그림체·주요 캐릭터·기본 톤·기본 장 수를 가진다 (open-questions #2) |
| 에피소드 | 게시물 한 편. 작품에 속한다(작품 없이 "단편"도 가능) |
| 톤 | 에피소드 분위기. 기본 목록: 공감, 코믹, 감동, 사이다, 공포, 정보 |

## 4. 기능 명세

### 작품
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| EPI-01 | 작품 만들기 | 이름, 한 줄 소개, 기본 그림체(STL), 주요 캐릭터(CHR), 기본 톤, 기본 장 수·출력 규격, 대표 이미지 | 1 |
| EPI-02 | 작품 목록 | 카드: 대표 이미지, 에피소드 수, 최근 발행일 | 1 |
| EPI-03 | 작품 보관 | 목록에서 숨김. 에피소드는 그대로 | 2 |
| EPI-04 | 연재 메모 | 작품 설정·세계관·고정 문구(예: 첫 장 인사말) — 각색 때 함께 참고 | 2 |

### 에피소드
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| EPI-10 | 에피소드 만들기 | 작품, 제목(나중에 가능), 재료 썰(제보 선택 또는 바로 입력), 톤, 목표 장 수. 만들면 Studio › Story로 | 1 |
| EPI-11 | 에피소드 목록 | 작품별 · 전체. 보기: 카드(대표 컷 썸네일) / 표. 칸: 제목, 작품, 단계·상태, 장 수, 비용, 수정일 | 1 |
| EPI-12 | 상태 | 제작 단계(각색·콘티·작화·검수·출력) / 완료 / 발행됨 / 보관 ([glossary.md](../planning/glossary.md) 3절). 단계는 작업에 따라 자동으로 바뀌고 직접 바꿀 수도 있다 | 1 |
| EPI-13 | 진행 표시 | 카드에 "작화 7/9컷 선택", "실패 1" 같은 진행 요약 | 1 |
| EPI-14 | 복제 | 구성(장·컷 배치, 등장 캐릭터, 설정)만 복제 또는 전체 복제 | 2 |
| EPI-15 | 에피소드 번호 | 작품 안 회차 번호 자동 매김, 직접 수정 | 2 |
| EPI-16 | 삭제 | 휴지통으로 (CMN-30). 발행됨 상태면 한 번 더 확인 | 1 |
| EPI-17 | 비용 합계 | 에피소드에 쓴 AI 비용 합계와 단계별 내역 (AIU-21) | 1 |
