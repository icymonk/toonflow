# AI 작업 · 사용량 · 설정

> 상태: 확정 · v1.1 · ID 접두어 `AIU`

## 1. 목적
모든 AI 작업(각색, 콘티, 그림, 점검)을 **대기열**로 다루고, 비용을 **실행 전에 보여 주고, 기록하고, 한도로 막는다.** 같은 작업이 두 번 과금되지 않게 한다.

## 2. 사용자 스토리
- 생성 버튼을 누르기 전에 대략 얼마가 드는지 알고 싶다.
- 이번 달에 얼마 썼는지, 어떤 에피소드에 많이 썼는지 보고 싶다.
- 실수로 한꺼번에 100컷을 생성해 큰돈이 나가는 일이 없었으면 한다.
- 실패한 작업은 돈이 나가지 않았으면 한다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| AI 작업 | AI를 부르는 일 하나. 종류·대상(에피소드·컷)·상태·비용·실패 사유·쓴 모델을 가진다 |
| 예상 비용 | 실행 전 표시하는 금액(또는 사용량 단위) |
| 실제 비용 | 작업이 끝난 뒤 기록되는 금액 |
| 사용량 한도 | 워크스페이스의 월 상한. 넘으면 새 작업이 시작되지 않는다 |
| 1회 확인 기준 | 이 금액을 넘는 요청은 한 번 더 확인 |

## 6. 권한
작업 실행은 편집자 이상. 한도·AI 설정은 소유자·관리자. 운영자는 전체 기본값·모델 목록·워크스페이스별 한도 상한을 정한다 (CMN-50).

## 7. 예외 상황
- 작업 중 한도를 넘음 → 이미 시작한 작업은 끝내고, 새 작업은 막는다. 한도 계산은 시작 전에 예상 비용만큼 미리 잡고 끝나면 실제 비용으로 맞춘다.
- 모델 장애 → 대기열에 "모델 장애" 표시, 자동 재시도 후 실패. 다른 모델로 바꿔 다시 시도 선택.
- 가격이 바뀜 → 예상 비용은 현재 가격 기준, 이미 끝난 작업 비용은 그대로.
