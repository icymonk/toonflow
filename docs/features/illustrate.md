# Illustrate · 작화

> 상태: 확정 · v1.1 · ID 접두어 `ILL` — 비용·대기열은 [ai-usage.md](./ai-usage.md), 캐릭터·그림체는 [characters.md](./characters.md), [styles.md](./styles.md).

## 1. 목적
컷마다 AI 이미지 후보를 만들고, 비교해서 하나를 고른다. 캐릭터·그림체를 고정해 컷끼리 같은 모습이 나오게 하고, 실패와 비용을 투명하게 다룬다.

## 2. 사용자 스토리
- 버튼 한 번으로 모든 컷 후보를 만들어 두고, 다 되면 고르기만 하고 싶다.
- 마음에 거의 드는데 손 모양만 이상하면 그 부분만 다시 그리고 싶다.
- 이전 후보와 새 후보를 나란히 놓고 비교하고 싶다.
- 실패한 컷이 왜 실패했는지 알고, 다시 돈을 쓰지 않고 재시도하고 싶다.
- 내가 그린 그림을 한 컷에만 넣고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 생성 입력 | 그림 생성에 넘기는 것: 그림체(STL) + 등장 캐릭터와 참조 이미지(CHR) + 컷 장면 설명·구도·표정(SBD-10) + 컷 비율(장 배치) |
| 후보 | 생성 결과 이미지 하나. 만든 설정이 함께 기록된다 |
| 선택 | 컷의 그림으로 쓸 후보 하나 |
| 다시 생성 | 같은 입력으로 새 후보 (비용 발생) |
| 다시 시도 | 실패한 작업을 다시 돌림. 이미 비용이 나간 결과가 있으면 그것을 가져온다 (비용 중복 없음) |
| 부분 수정 | 이미지 일부를 칠해서 그 부분만 다시 그리기 |

## 4. 기능 명세

| ILL-07 | 그림체·캐릭터 고르기 | 작화 단계 왼쪽 위에서 작품·이번 화 그림체와 작품 주요·이번 화 등장 캐릭터를 바로 고른다. 지금 상태를 한 줄로 보여 주고, 그림체나 캐릭터가 비어 있으면 펼쳐 둔다 | 1 |

## 6. 권한
생성·선택은 편집자 이상. 보기 전용은 후보 보기만.

## 7. 예외 상황
- 한도에 닿음 → 생성 버튼 비활성 + 남은 한도·한도 바꾸기(소유자) 안내 (AIU-20).
- 컷 장면 설명이 생성 뒤 바뀜 → "영향 받음" (STU-12). 자동으로 다시 생성하지 않는다.
- 캐릭터 참조 이미지가 삭제됨 → 생성 입력에 경고, 이름·외형 설명만으로 진행 가능.
- 브라우저를 닫아도 작업은 계속, 돌아오면 결과가 있다.
