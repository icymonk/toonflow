# Inbox · 제보함

> 상태: 초안 · v0.1 · ID 접두어 `INB`

## 1. 목적
독자 제보와 작가가 직접 모은 썰을 한곳에 모으고, **사용 동의와 개인정보를 지키면서** 쓸 썰을 골라 에피소드로 넘긴다.

## 2. 사용자 스토리
- 인스타 DM으로 받은 썰을 복사해 붙여 넣고, 나중에 쓸지 표시해 두고 싶다.
- 독자가 링크로 직접 썰을 보내고, 각색·게시에 동의했다는 기록이 남았으면 한다.
- 제보 속 실명·회사명·학교명이 그대로 그림에 나가지 않게 하고 싶다.
- 채택한 썰이 언제 어떤 에피소드로 나갔는지 보고 싶다.
- (제보자) 내 이야기가 게시되면 알림을 받고, 마음이 바뀌면 철회하고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 제보 | 독자가 제보 링크로 보낸 썰 |
| 직접 등록 | 작가가 붙여 넣거나 쓴 썰 (출처 메모 가능: "DM", "댓글", "내 경험") |
| 제보 링크 | 작가(워크스페이스)마다 하나 있는 공개 제보 페이지 주소 |
| 사용 동의 | 제보자가 제출 때 체크한 허락 범위 |
| 가림 처리 | 실명·연락처 등 개인정보를 표시만 가리거나 바꿔 쓰기 |

## 4. 기능 명세

### 모으기
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| INB-01 | 직접 등록 | 제목(없으면 첫 줄), 본문, 출처 메모, 태그. 여러 개를 줄 구분으로 한꺼번에 붙여 넣기 | 1 |
| INB-02 | 제보 링크 | 공개 페이지: 작가 소개, 받는 썰 주제 안내, 본문, 닉네임(선택), 연락처(선택, 결과 알림용), 동의 체크 | 3 |
| INB-03 | 제보 주제 설정 | 작가가 "요즘 받는 썰: 회사 썰, 연애 썰" 같은 안내와 질문 칸(예: "언제 있었던 일?")을 추가 | 3 |
| INB-04 | 제보 받기 켜기·끄기 | 끄면 링크에 "지금은 제보를 받지 않아요" | 3 |
| INB-05 | 스팸 방지 | 짧은 시간 같은 곳에서 반복 제출 차단, 너무 짧은 글 거절, 금칙어 | 3 |
| INB-06 | 이미지 첨부 | 제보에 캡처 이미지 첨부 (최대 3장). 개인정보 위험이 커서 기본 끔 | 3 |

### 동의 · 개인정보
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| INB-10 | 사용 동의 | 필수: 각색·게시 허락, 개인정보는 바꿔서 쓴다는 안내 확인. 선택: 크레딧 표기(닉네임), 결과 알림 (open-questions #9). 동의 문구는 작가가 기본 문구에서 고칠 수 있고, 제출 당시 문구가 그대로 기록된다 | 3 |
| INB-11 | 동의 기록 보기 | 제보마다 동의한 항목·문구·시각 | 3 |
| INB-12 | 동의 철회 | 제보자는 제출 후 받은 확인 링크(연락처를 남겼으면 그곳으로도)로 철회. 게시 전이면 "철회됨"으로 바뀌고 내용 가림, 연결된 에피소드에 경고. 게시 후면 작가에게 알림 | 3 |
| INB-13 | 개인정보 자동 점검 | 이름·전화번호·이메일·주소·학교·회사명처럼 보이는 부분을 표시하고 바꿀 말 제안 ("김민수" → "A씨") | 2 |
| INB-14 | 가림 처리 | 표시한 부분을 바꾼 글로 각색에 넘긴다. 원문은 작가만 열람 | 2 |
| INB-15 | 연락처 분리 | 제보자 연락처는 목록·각색 화면에 보이지 않고 "알림 받기 켜짐"만 표시 | 3 |

## 5. 화면 구성
| 화면 | 주요 내용 |
| --- | --- |

| 제보 링크 페이지 (공개) | INB-02, 10. 제출 후 감사 문구 + 확인 링크(철회용) |

| 모바일 | 목록 + 상태 바꾸기 + 메모 (원본 6절: 모바일은 제보 검토 최적화) |

## 6. 권한
보기는 워크스페이스 멤버(보기 전용은 개인정보 가림), 선별·등록은 편집자 이상. 제보자는 자기 제보 철회만.

## 7. 예외 상황
- 철회된 제보로 만든 에피소드가 작업 중 → 에피소드 위에 경고, Export 막지 않고 확인 Dialog.
- 14세 미만으로 보이는 제보자 → 제보 페이지에 "만 14세 이상만" 안내 (open-questions #19). 자동 판정은 하지 않는다.
- 제보 링크 비활성 상태에서 제출 → 거절 안내.
- 혐오·불법 내용 → 반려 + 신고(CMN-40).

## 9. 리뷰 질문
- 지금 썰은 주로 어디서 받나(DM, 댓글, 구글폼)? 직접 등록에 "출처" 선택지를 그에 맞춘다.
- 제보자 연락처를 받을 것인가? 받으면 개인정보처리방침이 필요해진다. 대신 "확인 링크"만 주는 방법도 있다.
- 게시 후 철회 요청이 오면 어떻게 할 생각인가? (안내 문구에 반영)
- 크레딧 표기는 캡션에 넣는가, 마지막 장에 넣는가? (PUB-12)
