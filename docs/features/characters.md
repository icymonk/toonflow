# Characters · 캐릭터

> 상태: 확정 · v1.1 · ID 접두어 `CHR`

## 1. 목적
캐릭터를 한 번 등록하면 모든 컷·에피소드에서 **같은 모습·같은 말투**로 나오게 한다. AI 웹툰에서 가장 큰 품질 문제(컷마다 얼굴이 바뀜)를 다루는 기능이다.

## 2. 사용자 스토리
- 작가 본인 캐릭터를 등록해 두고 매 에피소드에 불러 쓰고 싶다.
- 화난 얼굴, 우는 얼굴처럼 표정별 참고 그림을 두고 싶다.
- 겨울 에피소드에서는 코트를 입히고 싶다.
- 제보 속 "상사"를 매번 같은 부장님 캐릭터로 그리고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 캐릭터 | 이름, 외형, 성격, 말투, 참조 이미지를 가진 등장인물. 워크스페이스 공용 (open-questions #2) |
| 참조 이미지 | 그림 생성 때 함께 넘기는 기준 그림. 대표(정면) 1장 + 표정·전신·의상 |
| 캐릭터 시트 | 같은 캐릭터를 정면·옆·전신·표정으로 모은 기준 이미지 묶음 |
| 역할 이름 | 제보 속 호칭("상사", "남친")을 캐릭터에 연결하는 별칭 |

## 4. 기능 명세
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| CHR-01 | 캐릭터 만들기 | 이름, 역할 이름(별칭 여러 개), 한 줄 소개 | 1 |
| CHR-02 | 외형 | 나이대, 성별 표현, 키·체형, 머리(색·모양), 눈, 특징(안경·점), 기본 의상. 그림 생성에 넘길 외형 설명이 자동으로 만들어지고 고칠 수 있다 | 1 |
| CHR-03 | 성격 · 말투 | 성격 키워드, 말투 예시 대사 2~3개. 각색·대사 생성에 쓰인다 (STO-03) | 2 |
| CHR-04 | 참조 이미지 | 대표 이미지 올리기 또는 생성. 생성할 때는 그림체(STL) 적용 후보 여러 개에서 고르기 | 1 |
| CHR-05 | 캐릭터 시트 생성 | 대표 이미지 기준으로 정면·옆·전신·표정 6종 생성 (비용 표시) | 2 |
| CHR-06 | 표정 · 의상 | 표정(기쁨·화남·슬픔·놀람·당황·무표정 …)과 의상(기본·겨울·잠옷 …)별 참조 이미지. 컷에서 표정·의상을 고르면 그 이미지가 넘어간다 | 2 |
| CHR-07 | 캐릭터 목록 | 카드(대표 이미지·이름·작품), 작품 필터(마지막 선택 기억), 검색. 작품을 고른 채 새로 만들면 그 작품의 주요 캐릭터로 | 1 |
| CHR-08 | 등장 기록 | 이 캐릭터가 나온 에피소드·컷 | 2 |
| CHR-09 | 작품 주요 캐릭터 | 작품에 주요 캐릭터 지정 → 새 에피소드에 자동 등장 후보 (EPI-01) | 1 |
| CHR-10 | 즉석 캐릭터 | 콘티에서 나온 새 인물을 바로 만들기 (SBD-12). 한 번 쓰는 단역은 "이번 에피소드만" | 1 |
| CHR-11 | 보관 · 삭제 | 보관하면 목록에서 숨김. 삭제는 휴지통 (쓰인 컷의 그림은 그대로) | 1 |
| CHR-12 | 일관성 테스트 | 같은 캐릭터로 장면 4개를 생성해 얼마나 같게 나오는지 확인 (비용 표시) | 2 |

## 5. 화면 구성
| 화면 | 주요 내용 |
| --- | --- |
| Characters | 캐릭터 카드 목록, "새 캐릭터" |
| 캐릭터 상세 | 왼쪽 대표 이미지·시트, 오른쪽 탭: 기본 정보 · 외형 · 말투 · 표정/의상 · 등장 기록 |
| 제작실 안 | 컷 속성 패널에서 캐릭터 선택 + 표정·의상 선택, 상세는 Drawer로 |

## 6. 권한
보기는 멤버 전원, 편집은 편집자 이상.

## 7. 예외 상황
- 실존 인물 사진을 참조 이미지로 올림 → 초상권 안내 문구, 확인 체크 후 사용.
- 대표 이미지 없이 생성 → 외형 설명만 쓰고 "일관성이 낮을 수 있어요" 안내.
- 선택한 이미지 AI가 참조 이미지를 받지 못함 → 외형 설명만 사용, 생성 입력에 표시 (open-questions #4).
