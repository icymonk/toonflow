# Review · 검수

> 상태: 초안 · v0.1 · ID 접두어 `REV` — 화면 틀은 [studio.md](./studio.md).

## 1. 목적
선택한 그림 위에 **말풍선·글자를 얹고**(식자), 게시 전에 품질·개인정보·표기를 점검한다.

## 2. 사용자 스토리
- 콘티에 적은 대사가 말풍선으로 자동으로 놓이고, 나는 위치만 조금 옮기고 싶다.
- 말풍선이 얼굴을 가리지 않았으면 한다.
- 게시 전에 오탈자, 실명, 전화번호가 남아 있지 않은지 확인하고 싶다.
- 작품마다 말풍선 글꼴·모양을 고정하고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 말풍선 | 대사를 담는 모양. 종류: 둥근(말), 구름(생각), 점선(속삭임), 뾰족(외침), 상자(내레이션), 효과음(글자만) |
| 꼬리 | 말풍선에서 말한 캐릭터를 가리키는 뾰족한 부분 |
| 식자 스타일 | 글꼴, 크기, 줄 간격, 말풍선 선 두께·색. 작품마다 기본값 |
| 검수 항목 | 게시 전 확인할 목록. 자동 점검 + 작가 체크 |

## 4. 기능 명세

### 말풍선
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| REV-01 | 자동 배치 | 콘티 대사(SBD-10)를 순서대로 말풍선으로 놓는다. 읽는 순서(위→아래, 왼→오른)와 빈 공간 기준 | 1 |
| REV-02 | 직접 편집 | 끌어서 이동·크기, 글 수정(콘티 대사와 같이 바뀜), 줄바꿈, 꼬리 방향 | 1 |
| REV-03 | 종류 · 스타일 | 말풍선 종류 바꾸기, 글자 굵게·크게(외침) | 1 |
| REV-04 | 식자 스타일 | 작품 기본 글꼴·크기·말풍선 모양. 글꼴은 상업 이용 가능한 목록에서 고른다 | 1 |
| REV-05 | 얼굴 피하기 | 자동 배치 때 인물 얼굴 위를 피한다 | 2 |
| REV-06 | 장 바깥 글 | 장 위·아래 여백에 내레이션 줄 넣기 | 2 |
| REV-07 | 말풍선 템플릿 | 자주 쓰는 모양·효과음 스티커 저장 (Assets) | 3 |

### 검수
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| REV-10 | 검수 목록 | 기본 항목: 모든 컷에 그림 있음 / 대사 누락 없음 / 말풍선이 잘리지 않음 / 오탈자 / 개인정보 / 출처·크레딧 / AI 생성 표기. 항목마다 미검수·확인 필요·통과 ([glossary.md](../planning/glossary.md) 3절) | 2 |
| REV-11 | 자동 점검 | 그림 없는 컷, 장 밖으로 나간 말풍선, 너무 작은 글자, 맞춤법 | 1 (그림·말풍선) / 2 (맞춤법) |
| REV-12 | 개인정보 점검 | 대사·캡션 속 이름·번호·주소 패턴, 그림 속 글자(간판·명찰)가 보이면 표시 | 2 |
| REV-13 | 이미지 품질 점검 | 손가락·얼굴 깨짐 등 이상해 보이는 컷 표시 (AI 점검, 선택, 비용 표시) | 3 |
| REV-14 | 검수 항목 편집 | 작품마다 항목 추가 ("로고 워터마크 있음") | 2 |
| REV-15 | 검수 완료 | 필수 항목이 통과하면 Export 탭에 ✓. 통과 못 해도 내보내기는 확인 후 가능 | 2 |

## 7. 예외 상황
- 대사가 길어 말풍선에 안 들어감 → 경고, 글자 줄이기·컷 나누기 제안.
- 그림이 바뀜(새 후보 선택) → 말풍선 위치 유지 + "영향 받음" 표시 (STU-12).
- 화면 미리보기와 출력 결과가 다르면 안 된다 → 같은 방식으로 그린다 (open-questions 3절 "말풍선 렌더링").
