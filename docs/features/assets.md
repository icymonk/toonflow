# Assets · 에셋

> 상태: 초안 · v0.1 · ID 접두어 `AST`

## 1. 목적
생성한 이미지와 참고 자료를 한곳에서 찾고 다시 쓴다. 용량을 보여 주고 정리한다.

## 2. 사용자 스토리
- 지난번 사무실 배경 컷을 이번 에피소드에 다시 쓰고 싶다.
- 포즈 참고 사진을 모아 두고 콘티에 붙이고 싶다.
- 용량이 얼마나 찼는지, 무엇이 많이 차지하는지 알고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 생성 이미지 | 컷 후보·캐릭터·그림체 샘플 등 AI로 만든 이미지. 만든 설정이 함께 남는다 |
| 참고 자료 | 작가가 올린 사진·그림 (포즈, 배경, 소품) |
| 출력본 | 내보낸 게시용 이미지 묶음 (PUB) |

## 4. 기능 명세
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| AST-01 | 모아 보기 | 탭: 생성 이미지 / 참고 자료 / 출력본. 격자 보기, 크게 보기 | 2 |
| AST-02 | 필터 · 검색 | 작품, 에피소드, 캐릭터, 그림체, 선택됨 여부, 기간, 태그. 생성 설명 글로 검색 | 2 |
| AST-03 | 올리기 | 참고 자료 올리기(끌어 놓기, 여러 장), 태그 | 2 |
| AST-04 | 다시 쓰기 | 컷 후보로 가져오기(ILL-31), 콘티 참고 이미지(SBD-15), 캐릭터 참조(CHR-04) | 2 |
| AST-05 | 출처 보기 | 이 이미지가 쓰인 곳·만든 설정(그림체·캐릭터·장면·모델) | 2 |
| AST-06 | 용량 | 워크스페이스 사용 용량, 종류별 비중, 한도 (AIU-23) | 2 |
| AST-07 | 정리 | 선택 안 된 후보 일괄 삭제(기간 지정), 휴지통으로 | 2 |
| AST-08 | 내려받기 | 선택한 이미지 원본 | 2 |

## 5. 화면 구성
Assets: 위 탭·필터, 가운데 격자, 오른쪽 선택 이미지 상세(AST-05).

## 6. 권한
보기는 멤버 전원, 올리기·삭제는 편집자 이상.

## 7. 예외 상황
- 쓰인 이미지 삭제 → 쓰인 곳을 보여 주고 확인. 선택된 컷 그림은 삭제할 수 없고 먼저 다른 후보를 선택해야 한다.
- 용량 한도 도달 → 올리기·생성 막고 정리 안내.
