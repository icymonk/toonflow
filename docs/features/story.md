# Story · 각색

> 상태: 확정 · v1.1 · ID 접두어 `STO` — 화면 틀은 [studio.md](./studio.md).

## 1. 목적
썰을 분석해 인스타툰 한 편에 맞는 이야기(각색안)로 바꾼다. AI가 여러 초안을 내고, 작가가 골라 고친다.

## 2. 사용자 스토리
- 긴 썰에서 웃긴 포인트가 어디인지 먼저 짚어 줬으면 한다.
- "코믹하게 6장" / "감동으로 8장"처럼 방향만 정하면 초안이 나오면 좋겠다.
- 마음에 드는 부분만 남기고 결말만 다시 써 달라고 하고 싶다.
- 처음 안과 고친 안을 비교해서 고르고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 썰 분석 | 요약, 등장인물, 핵심 장면(웃음·반전 포인트), 민감 요소 |
| 각색안 | 제목 후보, 한 줄 로그라인, 장면 흐름(기·승·전·결), 장면별 대사 초안, 마지막 장 마무리(펀치라인) |
| 사용 중 각색안 | Storyboard 단계로 넘어갈 각색안 하나 |

## 4. 기능 명세

### 입력
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| STO-01 | 재료 썰 | 연결된 제보(가림 처리된 글, INB-14) 또는 직접 입력. 여러 썰 연결 가능 (open-questions #21) | 1 |
| STO-02 | 각색 설정 | 톤, 목표 장 수, 화자(1인칭 작가 시점 / 3인칭, 에피소드마다 선택, 기본 1인칭), 등장 캐릭터 지정(작품 주요 캐릭터 기본), 추가 요청(자유 입력) | 1 |
| STO-03 | 작품 참고 | 작품 연재 메모·고정 문구(EPI-04), 캐릭터 말투(CHR-03), 같은 작품 직전 화의 줄거리(현재 각색안의 요약·장면·마무리)를 자동으로 함께 넘긴다 | 2 |

### AI 생성
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| STO-10 | 썰 분석 | 요약 3줄, 등장인물 → 캐릭터 연결 제안("상사" → 부장님 캐릭터), 핵심 포인트, 민감 요소(실명·특정 가능 정보·혐오 표현) 경고 | 1 |
| STO-11 | 각색안 만들기 | 기본 1안, 필요하면 3안까지(개수 선택, 비용 표시). 각 안은 같은 형식(3절) | 1 |
| STO-12 | 다시 만들기 | 같은 설정으로 새 안, 또는 요청 덧붙여서("결말 더 반전 있게") | 1 |
| STO-13 | 부분 다시 쓰기 | 각색안에서 문단·대사를 골라 "다시 쓰기 / 더 짧게 / 더 웃기게 / 말투 바꾸기" | 2 |
| STO-14 | 제목 · 캡션 후보 | 제목 후보 5개 (캡션은 PUB-10) | 1 |

## 5. 화면 구성
| 영역 | 내용 |
| --- | --- |
| 왼쪽 | 각색안 목록(STO-21) |
| 가운데 | 선택한 각색안 편집기: 제목, 로그라인, 장면 흐름, 장면별 대사 |
| 오른쪽 | 재료 썰(STO-24), 썰 분석(STO-10), 각색 설정(STO-02), "각색안 만들기" 주 버튼(비용 표시) |

## 6. 권한
편집자 이상.

## 7. 예외 상황
- 썰이 너무 짧음 → "장면이 부족해요. 상황·대사를 더 적거나 그대로 진행" 안내.
- 썰이 너무 김(모델 한도 초과) → 분석 단계에서 요약본으로 각색할지 묻는다.
- 콘텐츠 정책 거절 → 거절 사유 + 수정 제안. 비용 발생 여부 표시.
- 민감 요소 경고가 남은 채 다음 단계 → 확인 Dialog (막지 않음).
