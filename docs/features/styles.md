# Styles · 그림체

> 상태: 초안 · v0.1 · ID 접두어 `STL`

## 1. 목적
작품의 화풍(선, 색감, 채색 방식, 배경 밀도)을 프리셋으로 고정해, 모든 컷이 같은 그림체로 생성되게 한다.

## 2. 사용자 스토리
- "파스텔톤 심플 인스타툰" 그림체를 정해 두고 모든 컷에 쓰고 싶다.
- 내 기존 그림 몇 장을 올려서 비슷한 느낌으로 그려지게 하고 싶다.
- 회상 장면만 흑백 그림체로 바꾸고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 그림체 프리셋 | 이름, 설명, 참조 이미지, 색감, 선·채색, 배경 밀도, 금지 요소, 사용할 모델 |
| 공통 그림체 | TOONFLOW가 기본 제공하는 프리셋 (예: 심플 라인, 파스텔, 굵은 선 코믹) |
| 금지 요소 | 그림에 나오면 안 되는 것 (글자, 워터마크, 사실적 사진풍 등) |

## 4. 기능 명세
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| STL-01 | 프리셋 만들기 | 이름, 설명(자유 글), 선(얇음·굵음·없음), 채색(플랫·수채·셀), 색감(파스텔·쨍함·흑백·지정 팔레트), 배경 밀도(단색·간단·자세히), 금지 요소 | 1 |
| STL-02 | 참조 이미지 | 기준 그림 1~5장. 내 그림이면 "내가 권리를 가진 그림" 확인 | 1 |
| STL-03 | 공통 그림체 | 기본 프리셋 3~5개를 복사해 시작 | 1 |
| STL-04 | 미리 보기 생성 | 같은 기준 장면 3개(인물·배경·클로즈업)로 이 그림체 샘플 생성 (비용 표시) | 1 |
| STL-05 | 비교 | 두 프리셋 샘플 나란히 | 2 |
| STL-06 | 모델 지정 | 프리셋마다 쓸 이미지 모델·품질 (AIU-30) | 2 |
| STL-07 | 컷별 그림체 바꾸기 | 컷 속성에서 이 컷만 다른 프리셋 (회상, 상상 장면) | 2 |
| STL-08 | 버전 | 프리셋을 고치면 버전이 올라가고, 기존 컷 후보에는 만들 때 버전이 기록 | 2 |
| STL-09 | 목록 · 보관 | 카드(샘플 이미지), 쓰는 작품 수 | 1 |

## 5. 화면 구성
| 화면 | 주요 내용 |
| --- | --- |
| Styles | 프리셋 카드, "새 그림체", 공통 그림체 |
| 그림체 상세 | 왼쪽 샘플·참조 이미지, 오른쪽 설정(STL-01), "샘플 생성" |

## 6. 권한
보기는 멤버 전원, 편집은 편집자 이상.

## 7. 예외 상황
- 특정 작가 이름·작품명으로 화풍을 지정 → 다른 작가 화풍 모방 안내 문구 (금지할지는 open-questions #11과 함께).
- 쓰고 있는 작품이 있는 프리셋 삭제 → 막고 보관 안내.
