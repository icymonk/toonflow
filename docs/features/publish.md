# Export · Publish · 출력과 발행

> 상태: 초안 · v0.1 · ID 접두어 `PUB` — Export는 제작실의 마지막 단계, Publish는 발행 기록 메뉴.

## 1. 목적
에피소드를 인스타그램에 바로 올릴 수 있는 이미지 묶음과 캡션으로 내보내고, 언제 어디에 게시했는지 기록한다.

## 2. 사용자 스토리
- 1080×1350 이미지가 순서대로 이름 붙어 ZIP으로 받아졌으면 한다.
- 캡션과 해시태그 초안을 받아서 고쳐 쓰고 싶다.
- 제보자 크레딧과 AI 생성 표기를 잊지 않고 넣고 싶다.
- 게시한 링크를 남겨 두고 어떤 제보를 썼는지 찾아보고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 출력 규격 | 비율(4:5 / 1:1 / 3:4)과 크기. 기본 4:5 1080×1350 (open-questions #7) |
| 출력본 | 한 번 내보낸 결과(이미지들 + 캡션). 내보낼 때마다 기록 |
| 발행 기록 | 게시 날짜, 게시 링크, 쓴 출력본 |

## 4. 기능 명세

### Export (제작실)
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| PUB-01 | 출력 규격 | 워크스페이스 → 작품 → 에피소드 순서로 기본값. 비율 바꾸면 미리보기에 잘리는 부분 표시 | 1 |
| PUB-02 | 미리 보기 | 인스타그램 화면처럼 넘겨 보기, 프로필 격자 썸네일 미리 보기 | 1 |
| PUB-03 | 내려받기 | 장별 이미지(PNG·JPG) + ZIP. 파일 이름 `작품_회차_01.jpg` 순서 | 1 |
| PUB-04 | 장 하나만 | 고친 장만 다시 내려받기 | 1 |
| PUB-05 | 장수 상한 경고 | 한 게시물 상한을 넘으면 경고, 두 묶음으로 나눠 출력 | 1 |
| PUB-06 | 워터마크 | 작가 아이디·로고를 장마다 같은 자리에 (작품 설정) | 2 |
| PUB-07 | 고화질 원본 | 출력 크기의 2배 이미지 (재편집·인쇄용) | 3 |

### 캡션 · 표기
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| PUB-10 | 캡션 초안 | 각색안 기반 캡션 + 해시태그 후보 (AI, 비용 표시). 작품별 고정 해시태그·인사말 | 2 |
| PUB-11 | 캡션 복사 | 한 번에 복사 | 2 |
| PUB-12 | 제보자 크레딧 | 제보자가 크레딧 표기에 동의했으면(INB-10) 닉네임 문구를 캡션 또는 마지막 장에 | 3 |
| PUB-13 | AI 생성 표기 | 캡션 문구·마지막 장 작은 표시. 기본 켜짐, 끌 때 확인 (open-questions #10) | 1 |
| PUB-14 | 철회 확인 | 재료 제보가 철회됐으면 내보내기 전 Dialog (INB-12) | 3 |

### Publish (발행 기록)
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| PUB-20 | 발행 표시 | 출력본에 "게시함" + 날짜 + 게시 링크. 에피소드 상태 → 발행됨 | 2 |
| PUB-21 | 발행 목록 | Publish 메뉴: 날짜순 발행 기록, 작품 필터, 쓴 제보·비용 | 2 |
| PUB-22 | 제보자 알림 | 발행 링크를 알림 원한 제보자에게 (INB-27) | 3 |
| PUB-23 | 게시 예정 | 게시 예정일 메모와 Home 표시 (실제 예약 게시는 5단계) | 3 |
| PUB-24 | 인스타그램 직접 게시·예약 | 계정 연결 후 바로 게시 | 5 |
