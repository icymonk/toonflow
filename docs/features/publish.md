# Export · Publish · 출력과 발행

> 상태: 확정 · v1.3 · ID 접두어 `PUB` — Export는 제작실의 마지막 단계, Publish는 발행 기록 메뉴.

## 1. 목적
에피소드를 인스타그램에 바로 올릴 수 있는 이미지 묶음·릴스용 영상과 캡션으로 내보내고, 언제 어디에 게시했는지 기록한다.

## 2. 사용자 스토리
- 1080×1350 이미지가 순서대로 이름 붙어 ZIP으로 받아졌으면 한다.
- 같은 에피소드를 컷마다 시간을 정해 릴스용 영상으로도 뽑고 싶다.
- 캡션과 해시태그 초안을 받아서 고쳐 쓰고 싶다.
- 제보자 크레딧과 AI 생성 표기를 잊지 않고 넣고 싶다.
- 게시한 링크를 남겨 두고 어떤 제보를 썼는지 찾아보고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 출력 규격 | 비율(4:5 / 1:1 / 3:4)과 크기. 기본 4:5 1080×1350 (open-questions #7) |
| 출력본 | 한 번 내보낸 결과(이미지들 + 캡션). 내보낼 때마다 기록 |
| 발행 기록 | 게시 날짜, 게시 링크, 쓴 출력본 |

## 4. 기능 명세

### 영상 (릴스용, 3단계)
완성된 컷을 순서대로 보여 주는 슬라이드 영상. AI로 그림을 움직이지 않는다(비용 없음). 화면 미리보기와 같은 렌더러로 만든다.

| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| PUB-30 | 영상 만들기 | 에피소드에서 영상 설정을 열면 컷 순서대로 타임라인이 만들어진다. 규격: 9:16 1080×1920(기본, 릴스) / 4:5 1080×1350 | 3 |
| PUB-31 | 보여 주는 단위 | **컷 단위**(기본: 컷 하나를 화면 가득, 그 컷의 말풍선과 함께) / 장 단위(완성된 장을 그대로) | 3 |
| PUB-32 | 컷별 시간 | 컷마다 보여 줄 시간(0.5~10초). 기본값은 대사 글자 수로 자동 추천(말풍선 없는 컷 1.5초, 대사 있으면 글자 수에 비례). 전체 길이 표시 | 3 |
| PUB-33 | 컷 움직임 | 컷마다: 없음 / 천천히 확대 / 천천히 축소 / 좌우 이동 / 위아래 이동. 움직임 크기 약·중·강 | 3 |
| PUB-34 | 전환 | 컷 사이: 바로 / 페이드 / 밀기(왼쪽·위). 전환 시간 기본 0.3초 | 3 |
| PUB-35 | 말풍선 등장 | 컷과 함께 / 대사 순서대로 하나씩(컷 시간을 나눠 씀) | 3 |
| PUB-36 | 배경음악 | 음원 파일 올리기(사용 권리 확인), 음량, 끝부분 페이드 아웃. 기본 제공 음원은 없다. 인스타그램 앱에서 음악을 붙일 사람을 위해 "음악 없이" 기본 | 3 |
| PUB-37 | 타임라인 · 미리 보기 | 재생·멈춤, 컷 막대 끝을 끌어 시간 조절, 모든 컷에 같은 시간 한 번에 적용, 영상 길이 상한(인스타그램 릴스 현재 상한, 개발 전 확인)을 넘으면 경고 | 3 |
| PUB-38 | 영상 내보내기 | MP4 내려받기, 진행 표시. 표지(첫 화면)로 쓸 컷 선택. AI 생성 표기·제보자 크레딧은 이미지 출력 설정(PUB-12·13)을 따라 마지막 화면에 | 3 |

## 7. 예외 상황
- 그림 없는 컷이 있음 → 빈 칸으로 보이는 미리보기 + 확인 Dialog.
- 검수 미완료 → 확인 Dialog (REV-15).
- 출력 중 실패 → 장 단위 재시도.
- 영상 만들기를 지원하지 않는 브라우저 → 지원 브라우저 안내 (개발 문서 architecture 6절).
- 올린 음원이 영상보다 짧음 → 반복 또는 끝에서 멈춤 선택.
