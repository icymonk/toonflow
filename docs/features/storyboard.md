# Storyboard · 콘티

> 상태: 확정 · v1.2 · ID 접두어 `SBD` — 화면 틀은 [studio.md](./studio.md).

## 1. 목적
사용 중 각색안을 **장·컷**으로 나누고, 컷마다 장면 설명·등장 캐릭터·표정·연출·대사를 확정한다. 이 내용이 그대로 그림 생성(Illustrate)과 말풍선(Review)의 재료가 된다.

## 2. 사용자 스토리
- 각색안을 넣으면 6장·9컷 정도로 자동으로 나눠 줬으면 한다.
- 컷마다 "누가, 어디서, 어떤 표정으로, 어떤 구도"인지 정리돼 있으면 좋겠다.
- 컷 순서를 끌어서 바꾸고, 컷을 쪼개거나 합치고 싶다.
- 마지막 장은 항상 펀치라인 한 컷으로 크게 두고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 장 | 게시물 이미지 한 장. 컷 1~8개와 배치(1컷 / 2컷 세로·가로 / 3컷 / 4컷 / 줄마다 컷 수를 정한 배치, 예: 위 3칸·가운데 2칸·아래 1칸)를 가진다. 맨 위에 장 제목을 둘 수 있다 (open-questions #8) |
| 컷 | 그림 한 칸. 아래 4절 SBD-10 항목을 가진다 |
| 장면 설명 | 그림에 들어갈 내용을 글로 적은 것. 그림 생성의 중심 입력 |
| 대사 | 말풍선에 들어갈 글. 종류: 말, 생각, 속삭임, 외침, 내레이션(상자), 효과음. 효과음도 그림에 그리지 않고 글자로 얹는다 (REV) |

## 4. 기능 명세

### 나누기
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| SBD-01 | 자동 콘티 | 사용 중 각색안 → 목표 장 수에 맞춰 장·컷 나누기 + 컷마다 SBD-10 초안 (비용 표시) | 1 |
| SBD-02 | 다시 나누기 | 장 수·컷 수를 바꿔 다시. 이미 그림이 있는 컷은 유지할지 묻는다 | 1 |
| SBD-03 | 빈 콘티로 시작 | AI 없이 장·컷을 직접 추가 | 1 |

### 컷 내용
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| SBD-10 | 컷 항목 | 장면 설명, 장소·시간, 등장 캐릭터(캐릭터 선택 + 그 컷의 표정·동작·의상), 구도(클로즈업 / 상반신 / 전신 / 원경 / 시점), 분위기·효과(집중선, 땀방울, 배경 흐림), 대사 목록(말한 캐릭터 + 종류 + 글) | 1 |
| SBD-11 | 대사 편집 | 대사 추가·순서·종류 변경. 글자 수가 많으면 경고(말풍선이 그림을 가림) | 1 |
| SBD-12 | 캐릭터 자동 연결 | 장면 설명·대사에 나온 이름 → 등록된 캐릭터 연결 제안 | 1 |
| SBD-16 | 등장 캐릭터 고르기 | 콘티 단계 왼쪽 위에서 작품 주요·이번 화 등장 캐릭터를 고른다. 고른 캐릭터의 기본 의상·성격·말투가 자동 콘티에 쓰인다. 그림체는 고르지 않는다(작화에서) | 1 |
| SBD-13 | 컷 메모 | 작가용 메모(그림에 반영 안 됨) | 1 |
| SBD-14 | AI 장면 다듬기 | 장면 설명을 그림 생성에 맞게 구체화("사무실" → "형광등 켜진 개방형 사무실, 늦은 밤") | 2 |
| SBD-15 | 참고 이미지 | 컷에 구도·포즈 참고 이미지 붙이기 (Assets에서 고르거나 올리기) | 2 |

### 구성 편집
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| SBD-20 | 장·컷 추가·삭제·복제 | 삭제는 실행 취소 가능 (STU-22) | 1 |
| SBD-21 | 끌어서 순서 바꾸기 | 컷을 같은 장 안·다른 장으로, 장 순서도 | 1 |
| SBD-22 | 쪼개기 · 합치기 | 대사가 많은 컷을 둘로, 짧은 두 컷을 하나로 | 2 |
| SBD-23 | 장 배치 | 장마다 배치 선택(SBD 용어). 한 장에 최대 8컷, 컷 수마다 고를 수 있는 배치가 있고 컷 수가 바뀌면 기본 배치로 돌아간다. 배치에 따라 컷 이미지 비율이 정해진다 | 1 |
| SBD-25 | 장 제목 | 장 맨 위에 큰 제목 띠(예: "POV : 여친이 배부르다고 할 때"). 선택이며, 넣으면 컷 칸은 그 아래로 줄어든다. 미리보기·출력·게시에 모두 들어간다 | 2 |
| SBD-26 | 한 장툰 | 목표 장 수가 1장이면 자동 콘티가 한 장에 4~8컷과 장 제목을 만든다. 마지막 컷은 펀치라인, 시간이 건너뛰는 컷은 내레이션 상자로 | 2 |
| SBD-24 | 고정 장 | 작품 설정에 표지 장·마지막 인사 장(고정 이미지·문구)을 두고 자동 추가 | 2 |

| SBD-31 | 대본 보기 | 모든 컷의 장면·대사를 한 문서처럼 이어서 보고 고치기 | 1 |

## 7. 예외 상황
- 목표 장 수가 인스타그램 한 게시물 상한을 넘음 → 경고 + 두 게시물로 나누기 제안 (open-questions #7).
- 등록 안 된 캐릭터가 컷에 나옴 → "새 캐릭터 만들기 / 이름만 두기"(이름만이면 그림은 장면 설명대로).
- 장면 설명이 비어 있는 컷 → Illustrate에서 생성 버튼 비활성 + 이유.
