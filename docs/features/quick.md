# Quick · 빠른 제작

> 상태: 초안 · v0.2 · ID 접두어 `QCK` — 만든 결과는 일반 에피소드라 [studio.md](./studio.md)에서 이어서 고친다.

## 1. 목적
제작실의 5단계를 하나씩 다루지 않고, **예시를 보고 누르는 질문 몇 개**에 답하면 나머지는 AI가 끝까지 만든다. 휴대폰에서 한 손으로도 한 편을 만들 수 있게 한다.

## 2. 사용자 스토리
- 쓸 썰이 없으면 AI가 추천한 주제를 누르고, AI가 만든 썰 중에서 고르고 싶다.
- 컷이 좁으니 대사 길이를 정해서 그림이 말풍선에 덮이지 않게 하고 싶다.
- 출퇴근길에 휴대폰으로 썰 하나를 넣고, 몇 번 눌러서 한 편을 받고 싶다.
- 형식·영상·그림체를 글로 설명하지 않고 예시를 보고 고르고 싶다.
- 등장인물이 꼭 사람일 필요는 없다. 고양이나 감자 같은 캐릭터로도 그리고 싶다.
- 다 만든 뒤 마음에 안 드는 컷만 다시 그리고, 더 손볼 게 있으면 제작실에서 이어서 하고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 질문 카드 | 한 화면에 질문 하나. 예시 그림이 붙은 선택지를 누르면 다음 질문으로 넘어간다 |
| 맡기기 | 질문에 답하지 않고 AI 추천값으로 넘어가기 |
| 확인 단계 | 자동 진행 중간에 멈춰서 결과를 보고 고르는 곳 (각색안·콘티). 기본은 꺼짐 |

## 4. 기능 명세

### 4-1. 시작
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| QCK-01 | 시작하는 곳 | 메뉴 "제작" 묶음 맨 위 **Quick · 빠른 제작**, Home의 "빠른 제작" 버튼, 제보 상세의 "빠른 제작"(그 제보가 썰로 들어간다) | 2 |
| QCK-02 | 작품 | 지금 고른 작품에 다음 화로 만든다. 작품을 고르지 않았으면 마지막에 쓴 작품, 없으면 "새 작품"을 만든다. 확인 화면(QCK-20)에서 바꾼다 | 2 |
| QCK-03 | 지난 답 기억 | 질문마다 지난번 답이 먼저 골라져 있다. 같은 설정으로 다시 만들 때는 누르기만 하면 된다 | 2 |

### 4-2. 질문 카드 (이 순서로 나온다)
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| QCK-10 | 질문 카드 공통 | 한 화면에 질문 하나, 선택지 2~5개를 예시 그림이 붙은 큰 카드로 보여 준다. 누르면 바로 다음 질문. 위쪽에 진행 점(1/7), "이전", "맡기기" | 2 |
| QCK-11 | ① 형식 | **한 장툰**(한 장에 4~8컷, 장 제목) / **여러 장**(4·6·8장) / **여러 화로 나누기**(긴 썰). 선택지마다 장·컷 배치 예시 썸네일 ([storyboard.md](./storyboard.md) SBD-23·26, [story.md](./story.md) STO-16) | 2 |
| QCK-12 | ② 영상 | **이미지만** / **영상도 만들기**. 영상을 고르면 이어서 **컷당 시간**(빠르게 1.5초 · 보통 3초 · 느리게 5초) 또는 **전체 길이**(15 · 30 · 60초, 컷 수로 나눠 컷당 시간을 정한다)를 고른다. 선택지마다 짧은 움직이는 예시 ([publish.md](./publish.md) PUB-30·32) | 2 |
| QCK-13 | ③ 그림체 | 워크스페이스 그림체 샘플 카드 중에서 고른다. 그림체가 없으면 기본 그림체 3~5개(심플 라인, 파스텔, 굵은 선 코믹 등)의 예시에서 고르고, 고른 것을 그림체로 저장한다 ([styles.md](./styles.md)) | 2 |
| QCK-14 | ④ 등장인물 모양 | **사람** / **동물**(고양이·강아지 등) / **사물·음식 의인화**(감자·콩 등) / **단순한 선 캐릭터** / **등록한 캐릭터 쓰기**. 예시는 고른 그림체로 그린 같은 장면. 등록한 캐릭터를 고르면 그 작품 주요 캐릭터가 기본으로 들어간다 | 2 |
| QCK-15 | ⑤ 이야기 방향 | **반전·웃음** / **감정선** / **원작에 충실** / **원문 그대로**(각색 없이, STO-25). 선택지마다 예시 한 줄 | 2 |
| QCK-16 | ⑥ 대사 길이 | **짧게**(말풍선 한 줄, 컷당 1개) / **보통**(두 줄, 컷당 2개) / **길게**(세 줄, 컷당 3개). 예시는 같은 컷에 말풍선이 얼마나 덮이는지 보여 준다. 기본은 한 장툰이면 짧게, 여러 장이면 보통. 콘티의 대사가 이 길이를 넘지 않게 만든다 ([storyboard.md](./storyboard.md)) | 2 |
| QCK-17 | ⑦ 썰 | **붙여넣기** / **제보함에서 고르기** / **AI가 만들어 주기**(QCK-18). 제보에서 시작했으면 건너뛴다 | 2 |
| QCK-18 | 썰 만들기 | AI가 **주제 칩 4~6개**를 추천한다(지금 작품의 지난 화, 고른 형식·등장인물 모양에 맞춰. 예: #회사 #연애 #고양이). 주제를 누르면 **한 줄 설명 3개**가 추천된다(예: "택배 기사님과 생긴 오해"). 누르기만 하면 되고 고쳐 써도 된다. 둘 다 건너뛰는 **알아서 3개 만들어 줘**도 있다. 그러면 AI가 썰 **3개**를 카드(제목 + 세 줄 요약, 누르면 전문)로 보여 준다. **고르기** / **다시 만들기**(3개 새로) / 카드의 **이렇게 바꿔 줘**(부연 설명을 쓰면 그 안을 고친 버전). 고른 썰은 제보함에 "AI가 만든 썰"로 저장된다 ([inbox.md](./inbox.md)) | 2 |
| QCK-19 | 썰 맞춤 질문 | 썰을 읽은 AI가 꼭 필요한 것만 1~2개 더 묻는다. 예: 펀치라인 후보 2~3개 중 고르기, 실명·회사명이 보이면 바꿀 이름 고르기 ([review.md](./review.md) 개인정보 점검) | 3 |
| QCK-20 | 확인 | 고른 답 요약(누르면 그 질문으로), 작품, 예상 비용·시간, 확인 단계 켜기(각색안·콘티, 기본 꺼짐) → **만들기**. 월 한도를 넘으면 시작하지 않는다 ([ai-usage.md](./ai-usage.md) AIU-20) | 2 |

### 4-3. 자동 진행
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| QCK-21 | 끝까지 자동 | 각색(방향대로 1안) → 콘티(형식·장 수대로) → 캐릭터 준비 → 모든 컷 그림(컷마다 첫 후보 선택) → 말풍선 자동 배치 → AI 점검 → (영상을 골랐으면) 영상까지 차례로 만든다 | 2 |
| QCK-22 | 캐릭터 자동 준비 | 등록한 캐릭터가 아니면, 썰에 나오는 인물을 고른 모양(QCK-14)과 그림체로 이번 화 캐릭터로 만든다. 모든 컷에서 같은 모습으로 그린다. 만든 캐릭터는 캐릭터 목록에 "빠른 제작" 표시로 남아 다음에 다시 쓸 수 있다 ([characters.md](./characters.md)) | 2 |
| QCK-23 | 확인 단계 | 확인 단계를 켰으면 각색안 2~3개를 카드로 넘겨 보고 고르기, 콘티 컷 목록(장면 한 줄 + 대사)을 보고 "좋아요 / 이 컷 다시" 뒤에 이어 간다 | 2 |
| QCK-24 | 진행 화면 | 단계 막대, 지금 하는 일, 지금까지 나온 컷 미리 보기, 예상 남은 시간. 화면을 닫아도 계속 만들고, 확인 단계나 완성 때 알림이 온다. **모두 취소**를 누르면 남은 작업을 멈춘다 | 2 |
| QCK-25 | 이어 하기 | 진행 중인 빠른 제작은 Home과 빠른 제작 첫 화면 위쪽에 보인다. 누르면 그 자리로 돌아간다 | 2 |

## 5. 화면 구성
| 화면 | 주요 내용 |
| --- | --- |
| 빠른 제작 첫 화면 | 진행 중인 빠른 제작(QCK-25), "새로 만들기", "같은 설정으로"(QCK-03) |
| 질문 카드 | 위: 진행 점·이전·맡기기 / 가운데: 질문과 예시 카드(2열) / 아래 고정: 지난 답이 있으면 "이대로 다음" |
| 확인 | 답 요약 목록, 작품, 예상 비용·시간, 확인 단계 스위치, 아래 고정 "만들기" |
| 진행 | 단계 막대, 컷 미리 보기 격자, 아래 고정 "모두 취소" · "제작실에서 열기" |
| 완성 | 넘겨 보기, 컷별 다시 그리기, 아래 고정 "내려받기" · "게시" |

- **모바일 우선**: 한 손으로 누르는 큰 카드, 중요한 버튼은 아래 고정, 가로 스크롤 없음. 데스크톱에서는 가운데 좁은 폭으로 같은 화면을 보여 준다.

## 7. 예외 상황
- 한 단계가 실패하면 그 단계에서 멈추고 **다시 시도** / **제작실에서 열기**를 보여 준다. 이미 만든 결과는 그대로 둔다.
- 진행 중 월 한도에 닿으면 남은 단계를 멈추고 알린다. 한도를 올리면 이어 할 수 있다.
- 썰이 너무 짧으면(한두 줄) 한 장툰을 권하고, 너무 길면 여러 화를 권한다.
- 그림체 예시나 캐릭터 예시를 그리는 데도 비용이 든다. 기본 예시는 미리 만들어 둔 그림을 쓰고, 워크스페이스 그림체는 이미 있는 샘플을 쓴다.
- AI가 만든 썰도 개인정보 점검을 거친다. 실존 인물·회사 이름은 넣지 않는다.
- 고른 형식·장 수와 썰 분량이 안 맞으면(장 수에 비해 너무 김) 콘티가 컷을 더 넣고, 확인 화면에서 "여러 화로 나누기"를 권한다.
