# Studio · 제작실 공통

> 상태: 초안 · v0.1 · ID 접두어 `STU` — 단계별 기능은 [story.md](./story.md), [storyboard.md](./storyboard.md), [illustrate.md](./illustrate.md), [review.md](./review.md), [publish.md](./publish.md).

## 1. 목적
에피소드 하나를 만드는 모든 단계를 **한 화면 틀** 안에서, 화면 이동을 최소로 하고 기다림 없이 이어서 작업하게 한다. 제작 시간에 가장 큰 영향을 주는 화면이다.

## 2. 사용자 스토리
- 컷만 고르면 오른쪽 패널이 그 컷 편집으로 바뀌었으면 한다.
- 이미지 생성을 걸어 두고 다음 컷 대사를 고치고 싶다.
- 콘티로 돌아가 대사를 바꿔도 이미 고른 그림이 날아가지 않았으면 한다.
- 실수로 지운 컷을 바로 되돌리고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 단계 탭 | Story · Storyboard · Illustrate · Review · Export |
| 컷 목록 | 왼쪽. 장 단위로 묶인 컷 썸네일과 상태 |
| 속성 패널 | 오른쪽. 선택한 장·컷의 편집 항목(단계마다 다름) |
| 영향 받음 | 앞 단계 내용이 바뀌어 뒤 단계 결과를 다시 봐야 하는 상태 |

## 4. 기능 명세

### 화면 틀
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| STU-01 | 3영역 레이아웃 | 왼쪽 컷 목록 · 가운데 미리보기/편집 · 오른쪽 속성 패널 ([design/ui-system.md](../design/ui-system.md) 6절). Story 단계는 컷 목록 대신 각색안 목록 | 1 |
| STU-02 | 컷 선택 = 편집 대상 | 목록·미리보기에서 컷을 누르면 속성 패널이 그 컷으로 바뀐다. 단계를 바꿔도 선택한 컷 유지 | 1 |
| STU-03 | 패널 접기 | 왼쪽·오른쪽 패널 접기, 폭 조절, 상태 기억 | 1 |
| STU-04 | 에피소드 정보 | 위쪽: 작품 › 에피소드 제목(바로 수정), 상태, 비용 합계 | 1 |

### 단계 이동
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| STU-10 | 단계 탭 | 언제든 어느 단계로든 이동. 탭에 단계별 완료 표시(✓) | 1 |
| STU-11 | 다음 단계 안내 | 넘어가는 조건([overview.md](../planning/overview.md) 7절)을 못 채우면 무엇이 남았는지 알려 주되 **이동은 막지 않는다** | 1 |
| STU-12 | 영향 받음 표시 | 앞 단계 수정 시 뒤 결과를 지우지 않고 "영향 받음" 표시. 예: 컷 장면 설명 수정 → 그 컷 이미지에 표시, 대사만 수정 → 말풍선만 표시. 표시를 눌러 "그대로 두기" 가능 | 1 |

## 5. 화면 구성
[design/ui-system.md](../design/ui-system.md) 6절 그림. 각 단계 문서의 "화면 구성"은 이 틀 안의 가운데·오른쪽 내용만 적는다.

## 6. 권한
편집은 편집자 이상, 보기 전용은 읽기·전체 미리보기·댓글.

## 7. 예외 상황
- 저장 실패(연결 끊김) → 위쪽 빨간 표시, 다시 연결되면 자동 재시도. 저장 안 된 채로 닫으려 하면 경고.
- 다른 기기에서 같은 에피소드 수정 → 나중 저장이 덮어쓰기 전에 "다른 곳에서 바뀜, 새로고침" 안내.
