# 계정 · 워크스페이스

> 상태: 확정 · v1.0 · ID 접두어 `ACC`

## 1. 목적
로그인하고, 작업 공간(워크스페이스) 안에서만 내 작품·캐릭터·제보·사용량이 보이게 한다. 처음엔 혼자 쓰지만 나중에 다른 작가·공동 작업자를 받을 수 있게 처음부터 워크스페이스 단위로 둔다.

## 2. 사용자 스토리
- 처음 로그인하면 바로 내 작업 공간이 생겨서 아무 설정 없이 썰을 넣고 싶다.
- (4단계) 그림 담당 친구를 초대해 같은 작품의 컷을 같이 만들고 싶다.
- (4단계) 외주 작업용 워크스페이스를 따로 두고 사용량을 나눠 보고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 워크스페이스 | 작품·캐릭터·그림체·제보·에셋·사용량 한도의 묶음. 데이터가 다른 워크스페이스와 섞이지 않는다 |
| 내 워크스페이스 | 가입하면 자동으로 생기는 첫 워크스페이스 |
| 멤버 · 역할 | 워크스페이스에 속한 사람과 권한 → [users-and-roles.md](../planning/users-and-roles.md) |

## 4. 기능 명세

### 로그인 · 계정
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| ACC-01 | 로그인 | Google, 이메일 링크 (open-questions #13). 비밀번호는 두지 않는다 | 0 |
| ACC-02 | 가입 제한 | 0~3단계는 운영자가 허용한 계정만. 4단계부터 대기 명단 → 승인 (open-questions #14) | 0 |
| ACC-03 | 프로필 | 이름(작가명), 프로필 이미지. 제보 링크 페이지에 보인다 | 0 |
| ACC-04 | 약관 동의 | 이용약관·개인정보처리방침·만 14세 이상 확인 (open-questions #11, #19) | 4 |
| ACC-05 | 로그아웃 · 다른 기기 로그아웃 | | 0 |
| ACC-06 | 계정 삭제 | 소유한 워크스페이스를 넘기거나 삭제한 뒤에만. 30일 뒤 완전 삭제 | 4 |

### 워크스페이스
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| ACC-10 | 내 워크스페이스 자동 생성 | 첫 로그인 때 "○○의 스튜디오" 생성, 소유자는 본인 | 0 |
| ACC-11 | 워크스페이스 설정 | 이름, 로고, 기본 작품, 기본 출력 규격(PUB-01) | 0 |

| ACC-13 | 워크스페이스 삭제 | 소유자만. 7일 유예 후 삭제, 유예 중 복구 가능 | 4 |
| ACC-14 | 소유권 이전 | 관리자에게 넘긴다 | 4 |
