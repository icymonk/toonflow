# 공통 · Home · 운영

> 상태: 초안 · v0.2 · ID 접두어 `CMN`

## 1. 목적
오늘 할 일을 한눈에 보는 홈, 알림·검색·휴지통 같은 공통 기능, 랜딩 페이지와 운영자 기능을 정의한다.

## 2. 사용자 스토리
- 앱을 열면 새 제보, 이어서 할 에피소드, 실패한 생성이 바로 보였으면 한다.
- 생성이 끝나면 다른 화면에 있어도 알고 싶다.
- 지운 에피소드를 며칠 안에 되살리고 싶다.

## 3. 용어
| 용어 | 뜻 |
| --- | --- |
| 이어서 하기 | 최근 작업한 에피소드와 그 단계로 바로 가는 링크 |
| 휴지통 | 지운 항목을 30일 보관하는 곳 |

## 4. 기능 명세

### Home
| ID | 기능 | 설명 | 단계 |
| --- | --- | --- | --- |
| CMN-01 | 이어서 하기 | 최근 에피소드 3~5개 + 마지막 단계·컷으로 바로 | 1 |

| CMN-03 | 이번 달 현황 | 만든 에피소드·발행 수, 사용량(한도 대비), 한 편 평균 제작 시간·비용 ([roadmap.md](../planning/roadmap.md) 3절) | 2 |
| CMN-04 | 빠른 시작 | "썰 등록", "새 에피소드" | 1 |
| CMN-05 | 처음 사용 안내 | 첫 로그인: 그림체 → 캐릭터 → 첫 에피소드 순서 안내 체크리스트 | 1 |

## 5. 화면 구성
| 화면 | 주요 내용 |
| --- | --- |
| Home | 위 빠른 시작, 이어서 하기 카드, 오늘 할 일 목록, 이번 달 현황 |
| 알림 | 위쪽 바 종 아이콘 → 목록 |
| 휴지통 | Settings 아래 또는 사이드바 아래 |
| 운영자 | 운영자에게만 보이는 메뉴 |

## 6. 권한
홈·알림·검색은 각자. 휴지통 되살리기·바로 삭제는 편집자 이상. 운영자 기능은 운영자만.

## 7. 예외 상황
- 휴지통 항목의 연결 대상이 이미 없음(예: 작품 삭제 후 에피소드 되살리기) → "단편"으로 되살림.
