# 제품 용어

> 상태: 확정 · v1.3 · 2026-10-21 — 화면 문구와 모든 문서의 용어 원본. 바꿀 때는 이 문서부터 고친다.

## 1. 메뉴
화면에는 **영어 메뉴 + 한국어 설명**을 함께 보여준다 (예: `Studio · 제작실`). 원본 5절.

| 메뉴 | 한국어 | 내용 |
| --- | --- | --- |
| Home | 홈 | 오늘의 작업과 전체 현황 |
| **제작** | | 매일 쓰는 제작 흐름 |
| Inbox | 제보함 | 독자 제보와 직접 등록한 썰 |
| Stories | 작품 | 작품(시리즈)·에피소드 목록 |
| Studio | 제작실 | 각색, 콘티, 작화, 검수, 출력 |
| Publish | 발행 | 발행 기록, 캡션, 제보자 크레딧 |
| **라이브러리** | | 만들어 두고 여러 에피소드에 다시 쓰는 재료. 그림체가 캐릭터보다 먼저(캐릭터 기준 그림을 그림체로 만든다) |
| Styles | 그림체 | 그림체 프리셋 |
| Characters | 캐릭터 | 캐릭터 프로필과 참조 이미지 |
| Assets | 에셋 | 생성 이미지와 참고 자료 |
| Pages | 표지·끝장 | 표지·끝장 페이지 디자인 (PUB-17) |
| Settings | 설정 | AI, 사용량·한도, 계정, 워크스페이스 |

## 2. 제작 단계
`Story → Storyboard → Illustrate → Review → Export`

| 단계 | 한국어 | 하는 일 |
| --- | --- | --- |
| Story | 각색 | 썰 분석과 각색 |
| Storyboard | 콘티 | 장·컷 분할과 대사 확정 |
| Illustrate | 작화 | AI 이미지 생성과 선택 |
| Review | 검수 | 말풍선, 품질, 개인정보 검수 |
| Export | 출력 | 인스타그램 게시용 파일 출력 |

## 3. 상태
색은 [design/ui-system.md](../design/ui-system.md) 2절 상태 토큰. "보통"은 회색(중립)이다.

### 제보 상태 (INB)
| 상태 | 뜻 | 색 |
| --- | --- | --- |
| 새 제보 | 아직 안 읽음 | 브랜드(점) |
| 검토 중 | 읽었고 판단 전 | 보통 |
| 채택 | 쓸 예정. 에피소드로 넘길 수 있음 | 성공 |
| 보류 | 나중에 다시 볼 것 | 경고 |
| 반려 | 쓰지 않음 | 보통(흐리게) |
| 사용됨 | 에피소드에 연결됨 | 성공(진하게) |
| 철회됨 | 제보자가 동의를 철회함. 내용 가림 | 오류 |

### 에피소드 상태 (EPI)
| 상태 | 뜻 |
| --- | --- |
| 각색 · 콘티 · 작화 · 검수 · 출력 | 지금 작업 중인 제작 단계 (원본의 `story`~`export`) |
| 완료 | 출력까지 끝남, 아직 게시 전 |
| 발행됨 | 게시함 (발행 기록 있음) |
| 보관 | 목록에서 숨김 |

### 컷 이미지 상태 (ILL)
| 상태 | 뜻 | 색 |
| --- | --- | --- |
| 비어 있음 | 후보 없음 | 보통 |
| 대기 · 생성 중 | AI 작업 진행 | 보통 + 진행 표시 |
| 후보 있음 | 후보는 있지만 선택 전 | 경고 |
| 선택됨 | 이 컷의 그림이 정해짐 | 성공 |
| 실패 | 생성 실패. 사유와 다시 시도 | 오류 |
| 영향 받음 | 앞 단계(장면·캐릭터)가 바뀌어 다시 볼 필요 | 경고 |

### 검수 상태 (REV)
| 상태 | 뜻 | 색 |
| --- | --- | --- |
| 미검수 | 확인 전 | 보통 |
| 확인 필요 | 자동 점검이 문제를 찾음 | 경고 |
| 통과 | 작가가 확인함 | 성공 |

### AI 작업 상태 (AIU)
`대기 → 진행 중 → 완료 / 실패 / 취소됨`. 실패는 사유(한도 초과, 콘텐츠 정책, 일시 오류 등)를 함께 보인다.

## 4. 자주 헷갈리는 말
| 쓰는 말 | 쓰지 않는 말 | 이유 |
| --- | --- | --- |
| 썰 | 사연, 스토리(메뉴명과 겹침) | 인스타툰 작가들이 쓰는 말 |
| 제보 | 투고, 접수 | 독자가 보낸 썰 |
| 각색안 | 시나리오, 스크립트 | Story 단계 결과물 |
| 장 | 페이지, 슬라이드 | 게시물의 이미지 한 장 |
| 컷 | 패널, 칸 | 그림 한 칸 |
| 후보 | 결과, 시안 | 한 컷에 대한 생성 이미지 |
| 다시 생성 | 재생성, 리롤 | 같은 설정으로 새 후보 |
| 부분 수정 | 인페인팅 | 이미지 일부만 다시 그리기 |
| 말풍선 | 대사창 | 글자가 들어가는 모양 |
| 영상 | 릴스, 동영상, 비디오 | 컷을 순서대로 보여 주는 슬라이드 영상 (PUB-30). 화면 버튼은 "영상 만들기", 파일은 MP4 |
| 컷 시간 | 길이, 듀레이션 | 영상에서 컷 하나를 보여 주는 시간 (PUB-32) |
| 타임라인 | 시퀀스 | 영상의 컷 순서와 시간을 보여 주는 막대 (PUB-37) |
| 사용량 | 크레딧, 토큰 | 결제 방식이 정해지기 전까지 (open-questions #3) |
