# 사용자 · 역할

> 상태: 초안 · v0.1 · 2026-10-19

## 1. 사용자 유형
| 유형 | 설명 | 가입 |
| --- | --- | --- |
| 작가 | 워크스페이스를 만들고 작품을 제작한다. 첫 사용자는 운영자 본인 | 필요 |
| 공동 작업자 | 다른 작가의 워크스페이스에 초대되어 함께 제작한다 (4단계) | 필요 |
| 제보자 | 작가의 제보 링크로 사연을 보낸다. 동의 범위를 고르고, 원하면 연락처를 남긴다 | **불필요** |
| 운영자 | 서비스 전체를 관리한다(가입 승인, AI 설정 기본값, 전체 사용량, 신고 처리). 처음엔 본인 | 필요 (운영자 권한) |

- 한 사람이 여러 워크스페이스에 속할 수 있다 (4단계). 1~3단계에는 **사람마다 내 워크스페이스 1개**만 있다.

## 2. 워크스페이스 역할
| 역할 | 설명 |
| --- | --- |
| 소유자 | 워크스페이스를 만든 사람. 멤버·한도·삭제를 관리한다. 1명 |
| 관리자 | 소유자와 같지만 워크스페이스 삭제·소유권 이전은 못 한다 |
| 편집자 | 제작 전부(제보 선별, 에피소드·캐릭터·그림체 편집, AI 생성)를 한다 |
| 보기 전용 | 작품과 진행 상태를 보고 댓글만 남긴다 (예: 검수자, 클라이언트) |

## 3. 권한 표
| 동작 | 소유자 | 관리자 | 편집자 | 보기 전용 | 제보자 |
| --- | --- | --- | --- | --- | --- |
| 제보 보내기 (제보 링크) | — | — | — | — | ✓ |
| 제보함 보기 | ✓ | ✓ | ✓ | ✓ (개인정보 가림) | — |
| 제보 선별·직접 등록 | ✓ | ✓ | ✓ | — | — |
| 작품·에피소드 만들기·편집 | ✓ | ✓ | ✓ | — | — |
| AI 작업 실행 (비용 발생) | ✓ | ✓ | ✓ | — | — |
| 캐릭터·그림체 편집 | ✓ | ✓ | ✓ | — | — |
| 내보내기·발행 기록 | ✓ | ✓ | ✓ | — | — |
| 댓글 | ✓ | ✓ | ✓ | ✓ | — |
| 사용량 보기 | ✓ | ✓ | ✓ (본인 사용분) | — | — |
| 사용량 한도·AI 설정 바꾸기 | ✓ | ✓ | — | — | — |
| 멤버 초대·역할 변경 | ✓ | ✓ (소유자 제외) | — | — | — |
| 워크스페이스 삭제·소유권 이전 | ✓ | — | — | — | — |
| 제보 동의 철회·삭제 요청 | — | — | — | — | ✓ (받은 확인 링크로) |

- 운영자는 워크스페이스 내용을 **기본으로 보지 않는다.** 장애·신고 처리 때만 기록을 남기고 접근한다 (open-questions #18).
- 권한은 화면에서 숨기는 것으로 끝내지 않고 **서비스가 매번 다시 확인**한다 (원본 7-2절). 특히 AI 작업은 요청한 사람이 그 워크스페이스의 편집 권한이 있는지 서버에서 확인한다.

## 4. 리뷰 질문
