# 출시 단계 & 성공 지표

> 상태: 확정 · v1.1 · 2026-10-19

## 1. 출시 단계

> 원본 9절의 결론대로 **첫 목표는 관리 화면이 아니라 "썰 하나 → 게시용 이미지 ZIP"까지 이어지는 수직 기능**이다. 0~1단계는 순서대로, 2단계 이후 묶음 사이 순서는 바꿀 수 있다. 원본 MVP 체크리스트 7개와의 대응은 2절.

| 단계 | 사용자가 할 수 있게 되는 것 | 완료 기준 |
| --- | --- | --- |
| **0 – 앱 셸 · 기반** | 브랜드 토큰·로고 자리·메뉴·라우팅이 있는 앱, 로그인(운영자 본인), 내 워크스페이스 자동 생성, AI 설정(운영자 키), **월 사용 한도와 사용량 기록** | 로그인 후 메뉴를 오가고, 한도를 넘는 AI 요청이 막힌다 |
| **1 – 첫 수직 기능** | 썰 **직접 등록** → 에피소드 만들기 → AI 각색(각색안 생성·수정·다시 생성) → 장·컷 나누기, 대사 편집 → 그림체 1개·캐릭터 등록(참조 이미지) → 컷 이미지 생성(대기열, 후보 여러 개, 선택, 실패 시 다시 시도) → 말풍선 배치·편집 → **4:5 이미지 + ZIP 내려받기** | 썰 하나를 넣어 한 편(기본 6장, 장당 1컷)을 처음부터 끝까지 TOONFLOW 안에서 완성해 내려받는다 |
| **2 – 제작 품질** | 각색안·컷·후보 버전 비교와 되돌리기, 부분 수정, 컷 이미지 직접 올리기, 캐릭터·그림체 관리 화면 완성(표정·의상), 검수 체크리스트·개인정보 점검, 캡션·해시태그, Assets 보관함, Home 대시보드, 휴지통, 키보드 단축키 | 두 번째 에피소드부터는 캐릭터·그림체를 다시 입력하지 않고, 같은 모습으로 나온다 |
| **3 – 제보함** | 작가별 **공개 제보 링크**, 제보자 동의(사용 범위·크레딧 표기), 동의 철회, 개인정보 가림, 선별 상태, 제보 → 에피소드, 발행 기록·제보자 크레딧, **릴스용 영상 출력**(컷별 시간·움직임·전환·배경음악, PUB-30~38), 모바일에서 제보 검토 | 독자가 링크로 보낸 썰이 동의 기록과 함께 제보함에 들어오고, 채택 → 에피소드 → 발행까지 연결된다 |
| **4 – SaaS 개방** | 가입 개방(대기 명단·승인), 워크스페이스 여러 개, 멤버 초대·역할, 워크스페이스·멤버별 사용량, 요금제·결제, 랜딩 페이지, 이용약관·개인정보처리방침, 운영자 화면, 다크 모드 | 다른 작가가 가입해 자기 워크스페이스에서 한 편을 만들고, 한도·요금 안에서 쓴다 |
| **5 – 확장** | 인스타그램 직접 게시·예약, 세로 스크롤 웹툰 등 다른 출력 형식, 댓글·검수 요청 등 협업, 다국어, 작품 공유 링크 | — |

## 2. 원본 MVP 체크리스트와의 대응
| 원본 항목 | 이 문서의 단계 |
| --- | --- |
| 브랜드 및 앱 셸 | 0 |
| Firebase 기반 (Auth, Firestore, Storage, 보안 규칙) | 0 (보안 규칙은 모든 단계에서 기능과 함께) |
| 제보 및 에피소드 | 직접 등록·에피소드 = 1, 웹 제보 = 3 (open-questions #12) |
| 스토리 및 콘티 | 1 (버전 비교는 2) |
| 이미지 파이프라인 | 1 (부분 수정은 2) |
| 렌더링 및 출력 | 1 (검수 체크리스트는 2) |
| SaaS 기반 (워크스페이스 격리, 사용량·비용 한도) | 격리·한도 = 0, 멤버·요금 = 4 |

## 3. 성공 지표
| 지표 | 정의 |
| --- | --- |
| **한 편 제작 시간** (핵심) | 에피소드 만들기 → 출력까지 걸린 시간. 작업한 시간 기준(자리 비운 시간 제외) |
| 한 편 비용 | 에피소드당 AI 비용 합계, 컷당 평균 생성 횟수 |
| 첫 후보 채택률 | 다시 생성 없이 첫 생성 후보 중에서 고른 컷 비율 (캐릭터·그림체 일관성의 대리 지표) |
| 생성 실패율 | 실패한 AI 작업 비율, 실패 사유별 |
| 각색 수정량 | AI 각색안을 얼마나 고쳐 썼는지 (각색 품질) |
| 제보 전환율 | 받은 제보 중 발행까지 간 비율 (3단계 이후) |
| 재사용 | 두 번째 이후 에피소드에서 새로 등록한 캐릭터 수(적을수록 좋음) |
